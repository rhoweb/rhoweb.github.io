RTL to GDSII: taking designs from code to tapeout-ready IC layouts.

the phi division bridges the gap between digital design and silicon fabrication. we handle synthesis, place-and-route, timing closure, and DRC/LVS verification -- everything needed to turn an RTL description into a manufacturable chip layout.

## focus areas
- logic synthesis (Yosys, OpenROAD)
- place and route
- static timing analysis
- DRC and LVS verification
- standard cell library design
- tapeout flows (OpenLane, OpenROAD-flow-scripts)
